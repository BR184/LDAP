# 项目进展记录 010 - LDAP 用户与分组单向同步

## 1. 里程碑说明

本次完成了基于当前设计文档的 LDAP 单向同步能力补强，重点围绕：

- 用户基础数据同步到 LDAP
- 部门 / 分组数据同步到 LDAP 组
- 用户与分组关联关系同步到 LDAP 组成员

完成时间：2026-04-16

## 2. 本次完成内容

### 2.1 新增 LDAP 分组服务

已新增：

- `LdapGroupService`
- `StubLdapGroupService`
- `SpringLdapGroupService`

用于处理：

- 分组创建
- 分组更新
- 分组删除
- 用户加入分组
- 用户移出分组
- 用户组关系同步
- 用户从全部分组移除

### 2.2 用户管理流程联动

已将用户管理模块与 LDAP 分组同步接通：

- 创建用户后
  - 创建 LDAP 用户
  - 按部门编码创建或更新 LDAP 组
  - 将用户加入对应分组
- 更新用户后
  - 更新 LDAP 用户属性
  - 若部门变更，则同步调整 LDAP 分组成员关系
- 删除用户前
  - 先从全部 LDAP 分组移除
  - 再删除 LDAP 用户条目

### 2.3 配置补充

已在 LDAP 配置中补充：

- `groups-ou`

用于统一管理 LDAP 分组目录位置。

## 3. 当前同步范围

当前从 MySQL 单向同步到 LDAP 的内容包括：

- 用户基础数据
- 部门 / 分组数据
- 用户与分组的关联关系

当前不包括：

- 业务角色直接同步为 LDAP 组
- 菜单权限同步到 LDAP
- LDAP 回写 MySQL

## 4. 设计原则

当前同步方案遵循以下原则：

- MySQL 是主数据源
- LDAP 是认证目录投影
- 固定映射规则由代码维护
- 因当前仅面向飞书导入场景，暂不做动态映射配置化
