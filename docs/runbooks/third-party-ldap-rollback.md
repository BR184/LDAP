# 第三方系统 LDAP 接入回滚手册

## 1. 触发条件

- 用户大面积无法登录
- Bind 账号异常
- TLS 证书配置错误
- 用户过滤器错误导致启用用户无法命中

## 2. 回滚步骤

1. 关闭目标系统的 LDAP 认证入口
2. 恢复目标系统原有的本地认证配置
3. 验证管理员账户仍可登录
4. 记录故障时间、影响范围和回滚责任人
5. 暂停新增接入或批量推广动作

## 3. 证据留存

- 错误截图需脱敏保存
- 回滚后的最终配置需脱敏保存
- 回滚操作时间和责任人需写入联调记录

## 4. 回滚后的复盘重点

- 是否误改登录字段
- 是否遗漏 `employeeType=ENABLED` 过滤条件
- 是否使用了非只读 Bind 账号
- 是否对缓存刷新时间估计错误
