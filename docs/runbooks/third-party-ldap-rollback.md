# 第三方系统 LDAP 接入回滚手册

## 1. 触发条件

- 用户大面积无法登录
- Bind 账号异常
- TLS 证书配置错误
- 用户过滤器错误导致启用用户无法命中

## 2. 回滚步骤

1. 关闭目标系统的 LDAP 认证入口
2. 恢复目标系统原有的本地认证配置
3. 验证管理员账户仍可登录
4. 记录故障时间、影响范围和回滚责任人
5. 暂停新增接入或批量推广动作

建议执行细化如下：

1. 登录目标系统后台
2. 找到认证或 LDAP 配置入口
3. 关闭 LDAP 登录入口或禁用对应 provider
4. 恢复原有本地认证配置快照
5. 使用本地管理员账户验证可登录
6. 如已删除或调整本地管理员入口，优先恢复该入口
7. 必要时恢复旧版配置文件并重启目标系统
8. 回滚完成后记录最终生效配置的脱敏快照

## 3. 证据留存

- 错误截图需脱敏保存
- 回滚后的最终配置需脱敏保存
- 回滚操作时间和责任人需写入联调记录

## 4. 回滚后的复盘重点

- 是否误改登录字段
- 是否遗漏 `employeeType=ENABLED` 过滤条件
- 是否使用了非只读 Bind 账号
- 是否对缓存刷新时间估计错误

## 5. 最小运维注意事项

- 回滚时优先保住本地管理员登录能力
- 不要在回滚过程中同时修改多项 LDAP 参数，避免混淆根因
- 若问题发生在业务高峰，先回滚认证入口，再安排复盘
- 回滚完成后应立即通知相关业务方当前登录入口变化
