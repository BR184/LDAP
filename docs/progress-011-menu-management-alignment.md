# 项目进展记录 011 - 菜单管理补全与设计对齐

## 1. 里程碑说明

本次完成了菜单管理模块从“仅支持菜单树查询”到“支持菜单 CRUD + 角色菜单树稳定渲染”的补全落地，并同步修订了设计文档中菜单范围与边界说明。

完成时间：2026-04-16

## 2. 本次完成内容

### 2.1 菜单管理接口补全

已新增以下菜单管理能力：

- 菜单详情查询
- 菜单创建
- 菜单更新
- 菜单删除
- 全量菜单树查询
- 当前用户菜单树查询

### 2.2 菜单业务规则落地

本次将此前讨论确认的菜单规则补充到代码中：

- 菜单仅支持 `CATALOG`、`MENU`
- 菜单不做启停接口
- 菜单不做多语言、多租户隔离、版本发布、按钮管理
- `menu_code` 创建后不允许修改
- 菜单 CRUD 仅管理员可执行
- 非根节点菜单父节点必须存在且必须为 `CATALOG`
- 菜单不允许挂载到自身或自身下级节点之下
- `MENU` 必须有组件路径，`CATALOG` 默认使用 `Layout`

### 2.3 角色菜单关系增强

为避免角色只绑定叶子菜单时前端菜单树出现断层，本次新增：

- 角色绑定菜单时自动补齐祖先目录菜单

同时新增：

- 新建菜单后自动绑定到 `ADMIN`
- 删除菜单时自动清理 `sys_role_menu` 关系
- 更新菜单 `min_permission_level` 时校验现有角色绑定冲突

### 2.4 权限初始化补充

新增菜单管理相关接口权限点：

- `MENU_DETAIL`
- `MENU_CREATE`
- `MENU_UPDATE`
- `MENU_DELETE`

并在数据库迁移中自动授予 `ADMIN`。
