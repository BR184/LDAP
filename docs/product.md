# LDAP 企业统一身份管理平台 — 产品

## 定位与目标用户

- 面向企业内部的统一身份管理平台（corp-idm-platform），由产品负责人（高健峰）主导需求。
- 目标用户：企业内部 IT 管理员（用户/部门/角色/权限的日常维护者）与需要接入统一认证的第三方系统使用者。
- 核心价值：一个可信身份源（用户+部门+角色），向下游系统（GitLab、Jenkins、Nexus、禅道、OpenWebUI、lumen_flow 等）提供统一 LDAP 认证与身份/部门/角色数据。

## 核心功能领域

### 用户管理
- 用户故事：管理员能创建/编辑/删除用户，维护用户资料（用户ID、姓名、工号、邮箱、内网邮箱、手机、职务、部门、兼职部门、准入开关），分配角色，重置密码，同步到 LDAP。
- 可验证边界：用户ID与工号唯一；内置系统管理员（admin/超级管理员）不可删除或移除超级管理员角色；管理员关闭的"准入"不被文件导入覆盖。
- 筛选体验：用户列表支持**快速筛选**（综合关键词/部门/在职状态/允许使用）+ **精确筛选**（折叠面板：用户ID精确、姓名/工号/手机/邮箱/职务模糊、部门规则、账号状态、来源、角色、创建时间范围）+ **部门规则筛选**（包含/排除、仅本部门/含下级、主/兼职归属、未归属部门，上限 20 条）。
- 已确认约束：筛选条件在点击「查询」后才生效；已选条件标签只反映已应用条件（不反映未应用的输入）。

### 部门管理
- 树形部门结构，支持新建/编辑/删除/同步 LDAP；部门有编码、层级、状态（启用/停用）。

### 角色与权限管理
- 角色 CRUD、权限级别、菜单绑定、权限授权；内置角色（普通用户/超级管理员/管理员）结构受保护，不可改权限级别/删除/停用。
- 角色组：将角色按业务域分组托管，支持协作者与组内角色成员管理；向第三方提供角色供应（快照/增量变更）。

### LDAP 控制面
- 面向第三方系统的 LDAP 接入框架：查询框架详情、获取系统模板（GitLab 等）、预检连通性。已真实联调 GitLab LDAP 登录（含首登自动建号、禁用即不可登录）。

### 飞书组织架构同步
- 飞书开放平台 API 同步 + 文件导入（导入计划/变更评审/冲突解决/回滚），将飞书用户/部门同步为平台身份源，并按导入生成/离职清理 LDAP 账号。

### 访问密钥（个人访问令牌）
- 用户可为自动化/第三方调用创建 PAT，选择权限范围（跟随账号或固定权限子集），支持轮换/撤销/查看密钥。

### 邮件与通知
- 邮件服务器配置与测试；忘记密码通过内网邮箱发送重置邮件。

## 优先级（当前阶段）

1. 用户/部门/角色/权限的日常管理（核心）。
2. 统一 LDAP 认证与第三方系统接入（GitLab/Jenkins/Nexus/禅道/OpenWebUI/lumen_flow）。
3. 飞书导入与目录同步（含冲突处理与回滚）。
4. 个人访问令牌与角色供应（面向自动化与下游系统）。

## 已确认的产品边界与承诺

- 身份数据以本平台为准（唯一权威源）；下游系统通过 LDAP/API 消费，不得反向覆盖管理员设置。
- 对外 API 兼容：已发布给下游的 V1 接口字段格式保持稳定，破坏性变更必须提前与用户确认（见 AGENTS.md）。
- 删除/离职类操作必须可追溯（审计日志）且默认保守（系统管理员受保护、批量删除需显式指定对象）。
