# 角色管理页补全设计方案

## 1. 背景

当前仓库中的角色管理页仍处于占位态，前端仅展示静态假数据和预留按钮，但后端已经具备较完整的角色管理能力：

- 角色列表、详情、创建、更新、启停用、删除
- 角色菜单绑定
- 角色权限授权

结合当前项目节奏，本次目标不是重做信息架构，而是在现有后台骨架上，将角色管理页补到“可实际完成角色维护”的可用状态。

## 2. 目标

- 将角色管理页从静态占位页补全为真实业务页
- 完成角色基础 CRUD 与启停用能力
- 完成角色菜单绑定与接口权限授权能力
- 保持与现有用户页、部门页一致的页面组织方式
- 补足角色菜单与权限已选回显所需的最小只读接口

## 3. 非目标

- 本次不重做菜单管理页
- 本次不重做权限树页
- 本次不引入角色详情独立页面
- 本次不实现前端按钮级 ACL 引擎
- 本次不重构同步中心、LDAP 控制面等其他业务页

## 4. 设计原则

- 保持在页面中：采用列表主页面加抽屉/弹窗，不增加额外详情跳转
- 一致性优先：交互模式对齐现有用户页和部门页
- 后端真规则，前端做体验：对象级权限和内置角色约束以后端为准
- 最小后端增量：仅补角色页回显所需只读接口，不改变现有保存接口语义
- 参考阿里系中后台设计：查询、表格、关系配置和危险操作模板化

## 5. 推荐方案

采用“角色列表页 + 角色表单抽屉 + 菜单绑定弹窗 + 权限授权弹窗”的单页方案。

### 5.1 页面结构

- 查询区
  - 角色编码
  - 状态
  - 查询 / 重置
- 工具栏
  - 结果总数
  - 新增角色
- 列表区
  - 角色编码
  - 角色名称
  - 权限等级
  - 是否内置
  - 状态
  - 备注
  - 操作列
- 操作弹层
  - 新增/编辑角色抽屉
  - 绑定菜单弹窗
  - 授权权限弹窗

### 5.2 交互设计

- 新增角色
  - 使用抽屉表单
  - 字段：`roleCode`、`roleName`、`permissionLevel`、`remark`
- 编辑角色
  - 使用同一抽屉表单
  - `roleCode` 只读
  - 可编辑：`roleName`、`permissionLevel`、`remark`
- 启用/禁用
  - 使用二次确认弹窗
  - 保存后刷新列表
- 删除角色
  - 使用危险操作确认
  - 若为内置角色或角色已绑定用户，直接展示后端错误提示
- 绑定菜单
  - 使用树勾选弹窗
  - 打开时加载“全部菜单树 + 当前角色已绑定菜单 ID”
  - 保存时全量覆盖提交，由后端自动补齐祖先菜单
- 授权权限
  - 使用树勾选弹窗
  - 打开时加载“全部权限树 + 当前角色已授权权限 ID”
  - 保存时全量覆盖提交

## 6. 后端契约

### 6.1 复用现有接口

- `GET /api/v1/roles`
- `GET /api/v1/roles/{id}`
- `POST /api/v1/roles`
- `PUT /api/v1/roles/{id}`
- `PUT /api/v1/roles/{id}/status`
- `DELETE /api/v1/roles/{id}`
- `PUT /api/v1/roles/{id}/menus`
- `PUT /api/v1/roles/{id}/permissions`
- `GET /api/v1/menus/tree`
- `GET /api/v1/permissions/tree`

### 6.2 新增只读接口

为支持“绑定菜单”和“授权权限”的勾选回显，补充两个轻量接口：

- `GET /api/v1/roles/{id}/menus`
  - 返回当前角色已绑定的菜单 ID 列表
- `GET /api/v1/roles/{id}/permissions`
  - 返回当前角色已授权的权限 ID 列表

这两个接口只承担回显职责，不返回完整树结构，由前端将“树数据 + 已选 ID”合并渲染。

- 扩展 `frontend/src/api/modules/role.ts`

- 扩展 `frontend/src/types/role.ts`
  - 角色列表项
  - 创建/更新 payload
  - 状态更新 payload
  - 菜单绑定 payload
  - 权限授权 payload
- 新增角色页组件
  - `RoleFormDrawer.vue`
  - `RoleMenuDrawer.vue`
  - `RolePermissionDrawer.vue`
- 改造 `frontend/src/views/role/RoleListView.vue`
  - 接入真实列表
  - 本地过滤与本地分页
  - 新增/编辑/启停用/删除
  - 菜单绑定
  - 权限授权
