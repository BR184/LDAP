# 删除首页与个人中心部门路径设计

## 目标

- 所有角色登录后统一进入个人中心，不再提供首页。
- 删除首页路由、导航入口、默认跳转和无引用页面实现。
- 个人中心显示完整部门层级路径，不显示部门编码。

## 权威数据模型

- `deptCode` 继续作为部门稳定 ID，仅用于数据关联。
- `deptName` 表示当前叶子部门名称，不承载层级路径。
- `departmentPath` 由后端根据部门祖先关系生成，例如 `华云三维 / 研发中心 / 平台研发部`。
- 前端只展示 `departmentPath`；字段为空时显示 `--`，不回退到编码。

## 路由与导航

- 根路由、登录后默认入口和无权限回退统一为 `/profile`。
- 删除 `/dashboard` 路由、首页导航配置和管理员专属首页菜单项。
- 删除无引用的 `DashboardView.vue`，旧地址进入现有 404 页面。

## 数据流

1. `/api/v1/auth/me` 查询当前用户。
2. 用户应用服务根据 `deptCode` 加载部门及祖先链。
3. 接口返回 `deptCode`、`deptName` 和 `departmentPath`，保持 ID、名称、显示路径语义分离。
4. 个人中心展示 `departmentPath`。

## 验证

- 后端单元测试覆盖完整部门路径和无部门场景。
- 前端类型检查与生产构建通过。
- 管理员和普通员工登录后默认入口均为 `/profile`。
- 搜索确认无 `dashboard` 路由、导航和页面引用。
- 通过 HTTP 接口验证个人中心返回完整部门路径。
