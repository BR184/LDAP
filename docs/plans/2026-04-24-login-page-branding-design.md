# 登录页品牌化优化设计

## 1. 背景

当前登录页仍保留明显的开发演示文案，如“企业后台 / Vue 3 / Element Plus”，与正式统一身份平台的产品化形象不够一致。

仓库中已提供两张品牌相关图片：

- `docs/image/image.png`
- `docs/image/image copy.png`

因此本次采用“保留现有双栏结构、加强品牌视觉”的最小方案，对登录页做一次品牌化优化。

## 2. 目标

- 去掉技术演示感较强的左侧说明文案
- 将主标题调整为“统一身份管理平台”
- 左上展示品牌 Logo
- 左下展示品牌大图，并固定在视觉区域底部
- 不改变登录表单交互与后端接口

## 3. 非目标

- 不重做登录接口逻辑
- 不修改右侧登录表单字段与校验
- 不引入新的图片素材来源

## 4. 设计方案

### 4.1 左侧品牌区

- 顶部放置 Logo
- 中部只保留平台主标题
- 移除：
  - `企业后台 / Vue 3 / Element Plus`
  - 平台副说明文案
  - 功能点列表

### 4.2 左下品牌大图

- 使用现有大图素材
- 放置在品牌区底部
- 采用 `object-fit: contain`，避免图片被硬裁切

### 4.3 右侧登录卡片

- 保持现有登录表单、交互、按钮和默认账号说明不变

## 5. 资源使用

- Logo：`docs/image/image.png`
- 大图：`docs/image/image copy.png`

部署到前端时复制到：

- `frontend/public/login-logo.png`
- `frontend/public/login-hero.png`

## 6. 验证方式

执行：

```powershell
npm.cmd run check
```

## 7. 结论

本次优化以最小改动提升登录页的品牌感和正式度，同时不影响现有登录逻辑和联调效率。
