# 手机号初始密码设计

## 目标

- 新用户首次创建 LDAP 账号时，默认密码使用该用户手机号。
- 手机号为空或不符合中国大陆 11 位手机号格式时，初始密码回退为 `123456`。
- 管理员重置密码仍固定为 `123456`，用户自行修改密码逻辑保持不变。
- 不修改任何现有 LDAP 用户密码。

## 权威策略

后端新增单一 `InitialPasswordPolicy`：

1. 对手机号执行首尾空白清理。
2. 符合 `^1\d{10}$` 时返回手机号。
3. 其他情况返回 `123456`。

所有首次创建或补建 LDAP 账号的路径必须调用该策略，包括：

- 管理员手工创建用户。
- 飞书导入创建 LDAP 用户。
- 用户手工同步到 LDAP 时补建账号。
- LDAP 对账自动修复缺失用户。
- 导入回滚时补建 LDAP 用户。

## 接口收敛

- 删除创建用户 API 的 `initialPassword` 请求字段。
- 删除前端创建用户表单与类型中的固定初始密码字段。
- 删除 `CreateUserCommand` 中不再生效的初始密码参数，避免客户端或调用者误以为可以指定初始密码。
- 管理员密码重置仍由原有独立常量和流程控制，不复用初始密码策略。

## 安全边界

- 初始密码不会写入日志、响应或审计明文字段。
- 规则只在 LDAP 条目首次创建时生效，更新已存在账号时不重置密码。
- 现有账号不会执行批量密码迁移。

## 验证

- 单元测试覆盖合法手机号、空手机号和非法手机号。
- 服务测试验证手工创建及导入创建向 LDAP 传入解析后的初始密码。
- 搜索确认首次创建路径不再硬编码 `123456`，密码重置路径仍保留 `123456`。
- 完整后端测试、前端构建和运行态健康检查通过。
