# 项目进展记录 009 - 角色菜单权限模型落地

## 1. 里程碑说明

本次完成了角色权限管理模块从“角色-接口权限原型”向“用户-角色-菜单 + permission_level”模型的升级落地。

完成时间：2026-04-16

## 2. 本次完成内容

### 2.1 角色模型升级

已为角色增加以下核心属性：

- `permission_level`
- `built_in`

并通过数据库迁移脚本完成初始化：

- `ADMIN`
- `NORMAL_USER`

其中：

- `ADMIN.permission_level = 1`
- `NORMAL_USER.permission_level = 3`

### 2.2 菜单模型落地

已新增：

- `sys_menu`
- `sys_role_menu`

并初始化菜单树结构，用于前端菜单树渲染。

### 2.3 已实现的角色管理能力

已实现以下接口与对应业务服务：

- 角色列表
- 角色详情
- 角色创建
- 角色更新
- 角色状态更新
- 角色删除
- 角色绑定菜单
- 用户分配角色
- 全量菜单树查询
- 当前用户菜单树查询

### 2.4 权限等级规则服务

已新增 `PermissionLevelRuleService` 及默认实现，用于处理：

- 用户生效权限等级计算
- 是否为管理员判断
- 用户基础信息修改边界
- 敏感操作边界
- 角色创建/更新/删除边界
- 角色菜单绑定边界
- 用户分配角色边界

### 2.5 用户管理联动

已将用户管理中的高风险操作与角色等级规则联动：

- 更新用户基础信息
- 用户状态更新
- 删除用户
- 重置密码

其中：

- 敏感操作仅管理员可执行
- 基础信息修改预留为“仅能修改低于自己权限等级的用户”

## 3. 数据库变更

本次新增迁移脚本：

- `V3__rbac_menu_model.sql`

主要内容包括：

- `sys_role` 增加 `permission_level` 与 `built_in`
- 初始化 `ADMIN`、`NORMAL_USER`
- 新建 `sys_menu`
- 新建 `sys_role_menu`
- 初始化管理员菜单绑定
- 初始化新增接口权限点

## 4. 当前实现状态

当前系统已形成以下分层模型：

- 用户 `User`
- 角色 `Role`
- 菜单 `Menu`
- 用户角色关系 `UserRole`
- 角色菜单关系 `RoleMenu`
- 接口权限 `Permission`

其中：

- 菜单负责前端渲染
- Casbin 负责接口准入
- `permission_level` 负责对象级操作边界
